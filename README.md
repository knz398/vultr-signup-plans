## 注册四步，易错点都在步骤里

### 第一步：填邮箱和密码

密码至少 10 位，大写字母、小写字母、数字、特殊字符里至少凑三种。页面有时会弹图形验证码，区分大小写。邮箱填错后面收不到验证信，提交前看两遍。

注册完成后会收到标题为 `Welcome to Vultr.com` 的邮件，点里面的 `Verify Your E-mail`。邮箱没验证，后续可能创建不了服务器。收不到先去垃圾箱翻，找不到就换微软或谷歌邮箱重新来一遍。

用支付宝付款时，账单信息要填拼音：

- `Your Name` 填姓名拼音，例如 `Zhang SanFeng`
- `Billing Address` 填区县拼音，例如 `Chaoyang Qu`
- `Billing City` 填城市拼音，例如 `Beijing`
- `Country/Region` 选 `China`
- `Billing Postal Code` 填六位邮编，例如 `100000`

## 创建第一台服务器

入口在 `Compute` → `Instances`，右上角 `+ Deploy`。

**服务器类型**按上面那张表选。个人博客和学习环境用 Cloud Compute，WordPress 和游戏服用 High Frequency，数据库和生产环境用 Optimized Cloud Compute。

**操作系统**优先 Ubuntu 22.04 LTS、24.04 LTS 或 Debian。这两个系统资料最多，出问题容易搜到答案。CentOS 已经停止维护，不要选。Vultr 也提供 WordPress、Nextcloud、WooCommerce 这类一键应用模板，不想手动装环境可以直接选。

三个附加项要留意：

- `Public IPv4` 不要取消勾选，取消了服务器就没有 IPv4 地址。
- `Limited User Login` 不建议勾选，勾了之后无法用 root 登录。
- `Automatic Backups` 不需要就关掉，它会额外收取大约月费 20% 的费用。

点 `Deploy` 之后，状态会从橙色 `Installing` 变成绿色 `Running`。官方给的数据是标准套餐 60 秒内完成部署，VX1 大约 15 秒。IP 地址、root 密码在 `Server Details` 的 `Overview` 页面看，SSH 端口默认 22。

### SSH 怎么连

Windows 用 Xshell、MobaXterm、Putty 都行，2018 年之后的系统也可以直接用自带终端。Mac 和 Linux 打开终端输入 `ssh root@你的服务器IP`，回车输密码。手机上装 ServerBox，Android 和 iOS 都有，填 IP、端口 22、用户名 root、密码，保存后连。

第一次登录建议先跑 `apt update && apt upgrade -y` 更新系统，需要的话用 `timedatectl set-timezone Asia/Shanghai` 把时区改成上海。

## 账单和限制，这几条最容易吃亏

**Stop 不等于停止计费。** 控制台上点 Stop 关机，费用照扣，只有 Destroy 销毁才真正停止。想省钱只有一个动作：删掉机器。

**自动备份另外收费**，大约是月费的 20%。开了就一直收，不需要记得关。

**升级可以，降级以控制台实际选项为准。** 不同资料对能不能降级说法不一致，下单时先按“只能升不能降”规划配置，别指望后期往下调。

**退款。** 余额可以申请退，需要开工单联系客服处理，赠金部分不退。不要相信“一个月无理由退款”这类说法，官方页面没有这个承诺。

**IP 被墙。** 销毁服务器重新创建就能拿到新 IP，不额外收费；也可以在 IP Manager 里付费换 IP，大约 $3/次。想保留数据的话，先新建一台同机房机器，用快照把数据带过去，新 IP 测通了再删旧的。
